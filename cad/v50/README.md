# Eurobox v50 CAD

This directory is updated automatically only after successful CAD, assembly-layout, box-clamp and STL-mesh validation.

- `FCStd/` – one editable FreeCAD file per individual part
- `STEP/` – the same individual parts as STEP exchange files
- `STL/` – the same validated printable meshes; click an STL in GitHub for the interactive 3D viewer
- `assembly/eurobox_v50_assembly.FCStd` – the complete FreeCAD assembly
- `assembly/ASSEMBLY_PREVIEW_v50.stl` – GitHub-viewable assembly preview only; not a production print part
- `assembly/PREVIEW_v50.png` – automatically rendered overview

Files here are generated outputs. The construction logic remains under `scripts/`.
