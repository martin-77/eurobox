# Eurobox v50 CAD

Parametric FreeCAD build for a removable 600 × 400 mm Eurobox carrier on the **FOCUS THRON² 6.8 EQP, model year 2023**.

The repository is the reproducible source of truth for v50: measured datums, CAD generation, collision checks, STEP/STL export, mesh validation and FreeCAD-rendered previews are all produced from the same build.

## Current v50 concept

- Two identical side modules, mirrored by a 180° rotation for the opposite side.
- Two rack-clamp stations per side at **X = ±90 mm**.
- Real measured rack tube diameter: **Ø12.42 mm**.
- Rack tube centre distance: **110.67 mm**.
- Eurobox: **600 × 400 mm**.
- Box lower rim: **16.45 × 16.45 mm** envelope.
- Box support datum: **Z = 39.54 mm**.
- Mudguard top datum: **Z = 34.54 mm**.
- Main transverse support: 32 × 30 mm double-web I-section.
- Guided clamp plate with two real through-holes.
- Separate printed test lead screw, lead nut, knob and retainers; no one-piece screw/knob shortcut.
- Printed prototype lead thread: **RH Ø8 × 2 mm**. This is a prototype interface and is intentionally separated from the later metal-screw / insert decision.
- No V-saddle on the diagonal rack stays.
- Anti-rotation feature is integrated into the inboard underside of the rack-clamp root. It is designed to bear against the non-coaxial rack edge on the real bike; the same round tube is not used as a fake anti-rotation validation datum.

## Validation gate

A build is not considered a usable v50 merely because FreeCAD exported files. CI must pass all hard checks before the final ZIP is produced, including:

- every exported source shape is one valid solid;
- STEP export and STEP re-import are valid and preserve volume;
- no rigid Base collision with the measured Ø12.42 mm rack tube;
- rack-lower and rack-pin interfaces remain collision-free where intended;
- conservative 16.45 × 16.45 mm Eurobox rim envelope remains clear;
- clamp plate moves through the full **0–4.5 mm** travel without Base/rim collision;
- both clamp-plate spindle holes remain real through-holes;
- lead-nut cartridge clears the fixed cage;
- lead-screw travel is checked through the complete plate travel;
- printed thread geometry is built as resolved geometry rather than a cosmetic cylinder;
- all final STL files pass trimesh validation.

The anti-rotation stop is treated separately: the exact contact point is a **non-coaxial physical rack datum**. Until that datum is measured on the bicycle, CI checks its geometry and tube clearance but does not invent a pass by testing rotation against the same circular tube.
